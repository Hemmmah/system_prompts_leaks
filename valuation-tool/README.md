# مُقيِّم الدخل — أداة تقييم عقاري بأسلوب الدخل

أداة عربية (RTL) تعمل في المتصفح بدون تثبيت أو خادم. افتح `index.html` مباشرة، أو استخدم الملف المستقل `dist/valuation-tool.html`.

## ما تحسبه

| المرحلة | المحتوى |
|---|---|
| الإيجار السوقي | تنظيف المقارنات الإيجارية (أرقام عربية، فواصل، شهري/سنوي، إجمالي/للمتر)، تعديلات %، كشف الشواذ (IQR / MAD / Z)، معدل مستخلص لكل فئة مع تجاوز مهني |
| الدخل وNOI | جدول وحدات مرتبط بالمقارنات، أساس تعاقدي/سوقي/مختلط، شغور، تحصيل، دخل آخر، مصروفات بنود (ثابت، ريال/م²، % EGI، % PGI) أو نسبة، تجاوز NOI مع مبرر |
| معدل الرسملة | معدلات ضمنية من الصفقات مع تعديل بالنقاط، النطاق الاستثماري، البناء التراكمي، تقارير السوق، ترجيح أو تحديد مهني، ونطاق المعدل |
| الرسملة المباشرة | القيمة، النطاق، تعديلات بعد الرسملة، القيمة عند ±100 نقطة أساس |
| DCF | نمو متغير لكل سنة، شغور لكل سنة، تحول العقود إلى السوق عند انتهائها، مصروفات رأسمالية، تخارج، نهاية/منتصف السنة، نطاق |
| المقارنات البيعية | سعر المتر بعد التعديل، الشواذ، القيمة والنطاق |
| الحساسية | مخطط تورنادو، جدول ثنائي لأي متغيرين، سيناريوهات باحتمالات، نقطة التعادل |
| التسوية | أوزان الطرق، تجاوز القيمة النهائية مع مبرر، التنبيهات، ملخص قابل للنسخ والطباعة |

## الملفات

- `src/engine.js` — كل الحسابات (دوال نقية، تعمل في المتصفح وNode).
- `src/app.js` — الواجهة. `src/sample.js` — الحالة النموذجية (أرقام توضيحية وليست بيانات سوق).
- `tests/engine.test.js` — اختبارات الحسابات: `npm test`.
- `build.mjs` — يبني الملف المستقل: `npm run build`.

البيانات تُحفظ في متصفح المستخدم فقط. استخدم «تصدير الحالة» لحفظ نسخة JSON و«استيراد حالة» لاسترجاعها.

## التحقق المستقل

`npm run validate` يبني نموذج إكسل مستقلاً للحالة النموذجية بمعادلات حية (`validation/reference-sample.xlsx`)، ويعيد حسابه عبر LibreOffice، ثم يطابق 44 بنداً من نتائج الأداة معه. شرط النجاح: فرق لا يتجاوز هللة واحدة في كل بند. يحتاج `openpyxl` و LibreOffice Calc.
